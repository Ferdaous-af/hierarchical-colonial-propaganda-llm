# Data documentation

The corpus used in this study was retrieved through the Impresso Media Monitoring of the Past Web App using the query `Perdicaris`.

The  workflow includes relevance classification, propaganda detection, intensity assessment, and the identification of ideological frames and rhetorical mechanisms.

The corpus selection and exclusion criteria are described in the accompanying paper. The complete newspaper texts and intermediate analytical datasets are not distributed through this repository. Access to the source material remains subject to the rights and access conditions of Impresso and its contributing institutions. Access the Impresso Web App here: [https://impresso-project.ch/app/](https://impresso-project.ch/app/)
